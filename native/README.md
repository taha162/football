# تطبيق «الملعب» الأصلي (أندرويد وآيفون)

تطبيق أصلي بشاشات مرسومة للهاتف (React Native مع Expo)، **ليس موقعاً داخل غلاف**. يتصل بقاعدة البيانات نفسها التي يستخدمها الموقع (Supabase)، فالحسابات والمباريات والمحادثات مشتركة بين الموقع والتطبيق.

## ما في المرحلة الأولى

| الشاشة | ماذا تفعل |
| --- | --- |
| تسجيل الدخول | برقم واتساب أو بالبريد، مع حدود المحاولات الخاطئة نفسها في الموقع (`/api/app/sign-in`)، ورمز تطبيق المصادقة لمن فعّله |
| الرئيسية | مبارياتك القادمة، ودعواتك |
| المباريات | القائمة والبحث بالاسم، وصفحة المباراة: الوقت، المكان، السعر، اللاعبون، الانضمام والمغادرة وقائمة الانتظار، والاتجاهات |
| الملاعب | القائمة والبحث، وصفحة الملعب: الملاعب والأسعار، أوقات الدوام، المباريات القادمة، الاتصال والاتجاهات |
| الرسائل | المحادثات (حيّة)، والمحادثة: الرسائل والصور، والإرسال، وعلامة القراءة |
| حسابي | ملفك، تسجيل الخروج، **حذف الحساب** (شرط في المتجرين) |
| الإشعارات | على الهاتف والتطبيق مغلق؛ الضغط يفتح المحادثة أو المباراة |

**ما يزال يُفتح من الموقع داخل التطبيق** (المرحلة التالية): إنشاء حساب، نسيت كلمة المرور، الحجز، تعديل الملف والإعدادات، الأصدقاء، حجوزاتي. والرسائل الصوتية والفيديو والمكالمات تُعرض باسمها في المحادثة وتُشغَّل من الموقع.

## كيف يعمل
- التطبيق يسأل الموقع عند فتحه أين قاعدة البيانات (`/api/app/config`)، فلا مفاتيح داخل التطبيق، وتغيير المشروع لا يحتاج نسخة جديدة.
- الجلسة محفوظة في خزنة الهاتف الآمنة (Keychain / Keystore).
- كل صلاحية تقررها قاعدة البيانات نفسها كما في الموقع.
- كل النصوص بالعربية، والاتجاه من اليمين إلى اليسار على كل هاتف.

## جرّب أندرويد الآن
GitHub ← **Actions** ← **Native app** ← آخر تشغيل ← **Artifacts** ← `al-malab-native-apk` ← فك الضغط وثبّت `app-release.apk`.

## آيفون
يحتاج حساب Apple Developer (99 دولاراً سنوياً). لا يلزم Mac: خدمة Expo السحابية (EAS) تبني النسخة وترفعها.
```bash
cd native
npm ci
npx eas-cli login            # حساب Expo مجاني
npx eas-cli build -p ios --profile production
npx eas-cli submit -p ios    # إلى App Store Connect
```
الخطة المجانية في Expo تكفي لبضع نسخ في الشهر. أو ابنِ على Mac: `npx expo prebuild -p ios` ثم Xcode.

## Google Play
1. حساب مطوّر (25 دولاراً مرة واحدة).
2. مفتاح التوقيع وأسراره في GitHub كما في `mobile/README.md` (الأسماء نفسها).
3. Actions ← Native app ← Run workflow ← علّم **release** ← نزّل `al-malab-native-aab` وارفعه.

## الإشعارات
المفاتيح نفسها في `DEPLOYMENT.md` القسم 22: `GOOGLE_SERVICES_JSON` في GitHub لأندرويد، و`FIREBASE_SERVICE_ACCOUNT` و`APNS_*` في Vercel. معرّف التطبيق `com.almalab.app` هو `APNS_BUNDLE_ID`.

## العلاقة بمجلد `mobile/`
`mobile/` هو الغلاف القديم الذي يعرض الموقع. **انشر `native/` في المتاجر**، فكلاهما بالمعرّف نفسه `com.almalab.app` ولا يُنشر إلا واحد. `mobile/` باقٍ احتياطاً، ويمكن حذفه لاحقاً.

## للمطوّر
- `npm run typecheck`: الأنواع.
- `npm run texts`: ينسخ نصوص الأخطاء من `messages/ar.json` إلى `src/lib/site-texts.json` حتى يقول التطبيق ما يقوله الموقع.
- مشروعا أندرويد وآيفون يُولَّدان من `app.config.ts` (`npx expo prebuild`) ولا يُحفظان في المستودع.
