# تطبيق «الملعب» لأندرويد وآيفون (الغلاف الذي يعرض الموقع)

> **للنشر في المتاجر استعمل التطبيق الأصلي في `native/`** (شاشات مرسومة للهاتف). هذا المجلد يعرض الموقع داخل غلاف، وباقٍ احتياطاً، وكلاهما بالمعرّف نفسه `com.almalab.app`، فلا يُنشر إلا واحد.

## كيف يعمل

- التطبيق غلاف أصلي (Capacitor 8) يفتح الموقع الحي `https://al-malab.vercel.app` داخل التطبيق، على صفحة `/ar/dashboard` (أو تسجيل الدخول لمن لم يدخل).
- **كل تحديث للموقع يصل إلى التطبيق فوراً** دون نسخة جديدة في المتجر. تحتاج نسخة جديدة فقط عند تغيير الغلاف نفسه: الأيقونة، الاسم، الصلاحيات، الإشعارات، أو إصدار Capacitor.
- الموقع يعرف أنه داخل التطبيق من عبارة `AlMalabApp` في متصفح التطبيق، فيمتد إلى حواف الشاشة ويترك مكان شريط الحالة والنتوء (`src/lib/app-shell.ts`). هذا للعرض فقط، ولا يغيّر أي صلاحية.
- **بلا إنترنت:** تظهر صفحة «لا يوجد اتصال بالإنترنت» مع «إعادة المحاولة»، ويعود التطبيق وحده عند رجوع الاتصال.
- **روابط المواقع الأخرى** (واتساب، الخرائط، روابط البريد) تُفتح خارج التطبيق في تطبيقاتها.
- **الصلاحيات** تُطلب عند أول حاجة فقط، لا عند التثبيت: الكاميرا (الصور والفيديو)، الميكروفون (الرسائل الصوتية والمكالمات)، الموقع (إرسال موقعك في المحادثة)، الإشعارات.
- **الاتجاه:** عمودي فقط. على آيفون: للآيفون فقط (يعمل على آيباد بحجم الآيفون)، فلا تُطلب صور آيباد في المتجر.
- **النسخ الاحتياطي في أندرويد** موقوف، حتى لا تنتقل جلسة الدخول إلى هاتف آخر.

## معرّف التطبيق: قرّره قبل أول رفع

المعرّف الحالي `com.almalab.app`. **لا يمكن تغييره بعد نشر التطبيق** في أي متجر. لتغييره قبل ذلك: عدّل `appId` في `capacitor.config.ts`، و`applicationId` و`namespace` في `android/app/build.gradle`، و`PRODUCT_BUNDLE_IDENTIFIER` في Xcode.

## جرّب أندرويد الآن (بدون أي أدوات)

1. GitHub ← تبويب **Actions** ← **Mobile app**.
2. افتح آخر تشغيل ناجح. كل PR يغيّر `mobile/` يبني نسخة، ويمكنك أيضاً الضغط على **Run workflow**.
3. في أسفل الصفحة ← **Artifacts** ← نزّل `al-malab-debug-apk` (ملف zip فيه `app-debug.apk`).
4. انقل الملف إلى هاتف أندرويد وافتحه. سيطلب الهاتف السماح بالتثبيت من هذا المصدر.

هذه نسخة تجربة، لا تُرفع إلى Google Play.

### ما يجب تجربته على هاتف حقيقي

لم يُجرَّب التطبيق على هاتف بعد: البناء يتم على GitHub، ولا يوجد هاتف في بيئة العمل. جرّب:
- تسجيل الدخول بواتساب: يفتح واتساب ثم ترجع إلى التطبيق وتكمل.
- إرسال صورة من الكاميرا ومن المعرض، وفيديو، ورسالة صوتية.
- مكالمة صوتية بين هاتفين، وزر السماعة.
- إرسال موقعك في محادثة.
- «حفظ» صورة: داخل التطبيق تُفتح في متصفح الهاتف، ومنه تحفظها.
- زر الرجوع في أندرويد: يرجع صفحة، ويغلق عارض الصور.
- إطفاء الإنترنت ثم فتح التطبيق: صفحة «لا يوجد اتصال»، ثم تشغيله.

## Google Play

**التكلفة:** حساب مطوّر Google Play: ‏25 دولاراً مرة واحدة.

1. **حساب المطوّر:** <https://play.google.com/console>. الحسابات الشخصية الجديدة تُلزَم باختبار مغلق مع 12 مختبِراً لمدة 14 يوماً قبل النشر للجميع (تحقّق من الشرط الحالي في Play Console). حساب الشركة (organization) لا يُلزَم بذلك، لكنه يحتاج رقم D-U-N-S.
2. **مفتاح التوقيع (مرة واحدة):** على أي حاسوب فيه Java:
   ```bash
   keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   base64 -w0 upload.jks > upload.jks.b64
   ```
   احفظ `upload.jks` وكلمتي المرور في مكان آمن خارج المستودع. **لا ترفعه إلى GitHub.**
3. **أسرار المستودع:** GitHub ← Settings ← Secrets and variables ← Actions ← New repository secret:
   - `ANDROID_KEYSTORE_BASE64`: محتوى `upload.jks.b64`.
   - `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS` (‏`upload`)، `ANDROID_KEY_PASSWORD`.
4. **البناء:** Actions ← Mobile app ← Run workflow ← علّم **release** ← نزّل `al-malab-release-aab`.
5. **الرفع:** Play Console ← أنشئ التطبيق ← Testing ← Closed testing (أو Production) ← ارفع `app-release.aab`. وافق على **Play App Signing** (تحتفظ Google بمفتاح النشر، ومفتاحك للرفع فقط).
6. **صفحة المتجر والنماذج:**
   - سياسة الخصوصية: `https://al-malab.vercel.app/ar/legal/privacy`
   - حذف الحساب: `https://al-malab.vercel.app/ar/legal/account-deletion` (يضيفه التعديل 124).
   - Data safety: الاسم، رقم الهاتف، البريد، الصور، الرسائل، الموقع التقريبي والدقيق (عند الإرسال فقط)، التسجيلات الصوتية. لا بيع ولا مشاركة لأغراض إعلانية.
   - التصنيف العمري، والجمهور المستهدف (ليس للأطفال)، ولقطات شاشة للهاتف.
   - **حساب تجربة للمراجِع:** التطبيق يتطلب الدخول، فأنشئ حساباً للمراجعة واكتب بياناته في App access.

كل رفع جديد يأخذ رقم إصدار أعلى تلقائياً (رقم تشغيل GitHub).

## App Store (آيفون)

**التكلفة:** برنامج Apple Developer: ‏99 دولاراً في السنة. **ويلزم جهاز Mac عليه Xcode** لبناء النسخة ورفعها.

1. **الحساب:** <https://developer.apple.com/programs/>.
2. **على الـMac:**
   ```bash
   cd mobile
   npm ci
   npm run sync
   npm run ios      # يفتح المشروع في Xcode
   ```
3. **في Xcode** ← هدف App ← Signing & Capabilities:
   - Team: حسابك.
   - أضف **Push Notifications** (ملف الصلاحية `App/App.entitlements` موجود).
4. **الرفع:** Product ← Archive ← Distribute App ← App Store Connect.
5. **App Store Connect:** صفحة التطبيق، لقطات شاشة للآيفون، سياسة الخصوصية، «App Privacy» (البيانات نفسها كما في Google)، و**حساب تجربة للمراجِع** في App Review Information.

**تنبيه عن مراجعة Apple:** قد ترفض Apple تطبيقاً تراه «موقعاً داخل غلاف» (البند 4.2). ما يساعد على القبول: الإشعارات الأصلية (التعديل 125، القسم أعلاه)، والصلاحيات الأصلية، وحذف الحساب من داخل التطبيق (التعديل 124، وهو إلزامي). إن رُفض، اكتب في الرد على المراجعة ما يقدّمه التطبيق كتطبيق: محادثات ومكالمات، وإشعارات فورية، وحجوزات.

## الإشعارات على الهاتف

تصل إلى الهاتف حتى والتطبيق مغلق: الرسائل الجديدة (إلا المحادثات المكتومة ومن حظرته)، وكل ما يظهر في الجرس، حسب إعدادات العضو. الضغط على الإشعار يفتح صفحته. الإعداد مرة واحدة، والتفاصيل في `DEPLOYMENT.md` القسم 22:

1. **أندرويد (Firebase، مجاني):**
   - <https://console.firebase.google.com> ← أنشئ مشروعاً ← أضف تطبيق Android بالمعرّف `com.almalab.app` ← نزّل `google-services.json`.
   - احفظ محتواه في GitHub كسرّ باسم `GOOGLE_SERVICES_JSON`، ليُبنى التطبيق معه. بدونه يعمل التطبيق بلا إشعارات، ولا يطلبها.
   - Project settings ← Service accounts ← Generate new private key ← احفظ الملف كاملاً في Vercel باسم `FIREBASE_SERVICE_ACCOUNT`.
2. **آيفون (من حساب Apple Developer):**
   - Certificates, Identifiers & Profiles ← Keys ← أنشئ مفتاحاً مع **Apple Push Notifications service (APNs)** ← نزّل ملف `.p8` (يُنزَّل مرة واحدة).
   - في Vercel: `APNS_KEY` (محتوى الملف)، `APNS_KEY_ID` (معرّف المفتاح)، `APNS_TEAM_ID` (معرّف فريقك).
   - نسخة تُشغَّل من Xcode مباشرة تحتاج `APNS_ENV=sandbox`. نسخ TestFlight والمتجر لا تحتاجه.
3. **قاعدة البيانات:** شغّل `…0051_push_notifications.sql`، ثم أوامر «الإيقاظ الفوري» في القسم 22، لتصل الإشعارات خلال ثوانٍ لا كل 15 دقيقة.

## تغيير الأيقونة أو شاشة البداية

تُرسم من شعار الموقع (`public/brand/`):
```bash
cd mobile
npm run assets:source   # assets/: الأيقونة وشاشة البداية بالحجم الكبير
npm run assets          # كل المقاسات لأندرويد وآيفون
```

## تجربة التطبيق على نسخة معاينة من الموقع

`APP_SITE_URL=https://<نسخة-المعاينة>.vercel.app npm run sync`، أو في GitHub: Run workflow ← site_url.
